# Quantitative & Fundamental Institutional Research (Track Record)

Independent forensic accounting diagnostics, variant consensus divergence, and supply chain capacity modeling evaluated ahead of quarterly earnings releases.

## Cryptographic Proof-of-Existence
All pre-earnings reports are SHA-256 hashed and anchored to the Bitcoin blockchain via OpenTimestamps (`.ots`) prior to market open, providing mathematically immutable verification of forecast publication time.

### How to Verify Any File Independently
1. Download both the report file (`.txt` or `.pdf`) and its companion receipt (`.ots`).
2. Drag and drop both files into [OpenTimestamps.org](https://opentimestamps.org/).
3. Or verify via CLI:
   ```bash
   ots verify <filename>.ots
